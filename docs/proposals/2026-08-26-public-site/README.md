一句话：**对外默认页面改成无需登录的只读公共主页**，供普通开发者浏览可用链与接入方式；
`/dashboard/*` 退为运维后台，保留 bearer 鉴权与控制操作。

## 边界

- 公共接口 `/api/public/*` 只读、无鉴权、带 token 也忽略，响应缓存 5 秒。
- 明确不对外暴露：端点 URL、健康明细、覆写与状态存储信息、用户可见错误数、审计。
- 开关 `admin.public_site`（默认开），关掉后公共页与公共接口全部 404，后台仍可用。
- 公共接口复用入口防护：请求体上限、并发背压、每 IP 限速、路径穿越校验。
